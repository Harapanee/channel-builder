# Studio の画面メモ(2026-10-07 に実機で通した手順)

座標は 1568×764 の座標系で取った目安。画面は変わるので、毎回スクリーンショットで確かめてから押す。ref(`find` の結果)でクリックすると、ダイアログの外を押した扱いで閉じることがある(公開設定ダイアログで発生)。ダイアログ内は座標で押すほうが安全。

## A/B テスト

- 詳細ページ `https://studio.youtube.com/video/<videoId>/edit` のタイトル欄の下に「A/B テスト」ボタン
- 既定は「タイトルのみ」。「サムネイルのみ」を押す。1枠目には現在のサムネが入っている
- ファイル入力は `find`「file input for thumbnail upload in A/B test dialog」で3つ取れる。**ref の並びが枠の順**。`file_upload` で1枚ずつ入れ、スクリーンショットで枠と画像の対応を確かめる(一度、1枠目の ref に案2を入れて上書きしたことがある)
- 3枚入ると下に「サムネイルのテストの準備ができました」→「テストを設定」→ トースト「変更内容を保存すると開始されます」→ 右上「保存」
- 確認: 開き直して「テスト実行中…」(公開中・メンバー先行中)か、「新しいテストを実行しますか? 現在のテストは削除されます」(予約中)が出ればキャンセルで閉じる。サムネ欄の「対象外」の ? にカーソルを置くと「動画が公開になっていない」と出る=予約中は正常

## 収益化

- 左メニュー「収益化」(`/video/<id>/monetization/ads`)。API でアップロードした直後は**オフ**
- プルダウン → 「オン」→「次へ」で自己評価のダイアログ。項目を1つずつ開く必要はない。`find`「上記のいずれも含まない」のチェックボックスへ `scroll_to` してクリック → 右側に「総合的な自己評価: 広告掲載に適切」→「送信」
- 「動画の途中にミッドロール広告を表示する」は既定でチェック済み。そのまま右上「保存」
- 確認: 開き直して `get_page_text` に「オン」

## メンバー先行

- 詳細ページ右の「公開設定」(`find`「動画の公開設定を編集」)→ ダイアログの「スケジュールを設定」
- 「メンバー限定から公開にする」を押すと、公開切替の日付は保たれるが**時刻が 0:00 に戻る**
- 時刻欄はキーボード入力を受け付けない。欄を1回クリックすると15分刻みの候補リストが出るので、スクロールして目的の時刻をクリック
- 右下「完了」→ 右上「保存」。Tab で欄を離れたりダイアログ外を押したりすると、設定は捨てられる
- 確認: 開き直して「メンバー限定から公開にする/すべてのチャンネル メンバー/日付 時刻」

## 終了画面

- 詳細ページ右の「終了画面」→ エディタ。テンプレート一覧の「2本の動画」(一覧のスクロール位置で場所が変わる)
- 既定で要素1=視聴者に適したコンテンツ・要素2=最新のアップロードになる。これが既定の方針なので、そのまま右上「保存」でよい。要素を選ぶにはタイムライン下部の帯をクリック
- 「視聴者に適したコンテンツ」は1つの要素にしか選べない(2つ目では灰色)
- 確認: 開き直してタイムラインの2本の帯の文言を読む
